# Library Management System

##  Overview
This is a simple **Java-based Library Management System** designed to manage books and users in a library.  
It demonstrates core concepts such as object-oriented programming, CRUD operations and persistent storage.

---

##  Features
- **Add Books** – Add new books with details like title, author and ISBN.
- **Search Books** – Search for books by title or author.
- **Display All Books** – View a list of all books in the library.
- **Borrow/Return Books** – Track which books are borrowed and returned.
- **Persistent Storage** – Save and load data using file serialization.

---

## ⚙️ Tech Stack
- **Java (JDK 17+)**
- **Java Swing** (for GUI)
- **File Serialization** (for persistent storage)

---

## 🗂️ Project Structure
- `Book.java` → Model class representing a book.  
- `LibraryDao.java` → Handles CRUD operations and file serialization.  
- `LibraryGUI.java` → Swing-based graphical interface for user interaction.  
- `LibraryManagementSystem.java` → Main entry point to run the application.
